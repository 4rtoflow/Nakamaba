# Markdown のサンプル

公開するときに、Markdown が HTML へ変換されることを確かめるためのサンプルです。トップの一覧のカードには、この見出しがタイトルとして出ます。

## 表

| 項目     | 内容                   |
| -------- | ---------------------- |
| 変換     | 公開するときに行います |
| タイトル | 最初の見出しを使います |

## コード

```js
console.log('こんにちは');
```

## 別のページ

[notes.md](notes.md) へのリンクは、公開するときに `notes.html` へ書き換わります。
